# 🐍 Meus Estudos em Python

Este repositório guarda todos os meus códigos, anotações e exercícios desenvolvidos durante o curso de Python do professor **Otávio Miranda**. O objetivo aqui é documentar minha jornada de aprendizado, desde os conceitos mais básicos até tópicos avançados.

## 📚 O que você vai encontrar aqui

Os arquivos estão organizados para acompanhar a minha evolução nas aulas. Alguns dos principais temas abordados até o momento incluem:

* **Lógica de Programação:** Variáveis, tipos de dados, condicionais (`if/else`) e laços de repetição (`for/while`).
* **Estruturas de Dados:** Listas e tuplas.
